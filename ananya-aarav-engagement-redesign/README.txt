Ananya & Aarav — Engagement Invitation Redesign
================================================

Files:
- ananya-aarav-engagement-redesign.html
    The complete, self-contained interactive prototype.
    Just double-click to open it in any browser — no server needed.
    All photos are embedded directly in the file (base64), so it
    works fully offline and can be shared as a single file.

- photo-assets/
    The individual cropped photos (JPG) pulled from the original
    site's screenshots, in case you want to reuse them elsewhere
    (e.g. pasting into Figma alongside this prototype).

The Gallery section reuses the supplied photo-assets JPGs in an
editorial layout with a fullscreen lightbox; no new photographs were added.
